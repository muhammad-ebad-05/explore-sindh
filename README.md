# 🏛️ Sindh Exploration Web Portal

A multi-page static web application dedicated to showcasing the rich history, culture, landmarks, and major cities of **Sindh, Pakistan**[cite: 2, 3, 4, 5]. Built entirely using **semantic HTML5** with clean internal page navigation[cite: 2, 3, 4, 5].

---

## 📍 Covered Pages & Regions

1. **Sindh (Main Page)** – Explores the ancient Indus Valley Civilization (Mohenjo-daro), Sufi heritage, culture (Ajrak & Topi), and geographical diversity.
2. **Karachi** – Highlights the economic hub, coastal beaches, colonial architecture, and iconic landmarks like Mazar-e-Quaid[cite: 4].
3. **Hyderabad** – Focuses on the historic city of perfumes, Pacco Qillo, traditional glass bangles (Kanch ki Churiya), and educational institutes[cite: 2].
4. **Sukkur** – Details the historic engineering marvels such as Sukkur Barrage, Ayub Bridge, Sadh Belo, and Masoom Shah Jo Minaro[cite: 5].

---

## ✨ Key Features

- 🔗 **Seamless Navigation:** Every page includes a quick navigation menu to switch effortlessly between Sindh, Karachi, Hyderabad, and Sukkur[cite: 2, 3, 4, 5].
- 🖼️ **Rich Visuals:** Each city page contains aligned regional imagery representing iconic landmarks[cite: 2, 3, 4, 5].
- 📜 **Semantic Markup:** Uses structured `<article>` and `<section>` tags for optimized text structure and readable content layout[cite: 2, 3, 4, 5].
- ⚡ **Pure HTML:** Developed strictly using HTML5 without external CSS or JS frameworks[cite: 2, 3, 4, 5].
