# Sindh Travel Guide & Cities Website 🏛️🌊

An informative, multi-page web development project showcasing the rich historical legacy, culture, major cities, and landmarks of Sindh, Pakistan.

---
🔗 Live Demo & Links
https://muhammad-ebad-05.github.io/explore-sindh/

## 📌 Project Overview

This project is a clean, semantic, multi-page HTML website structured to provide dedicated reading sections and navigation across key cities in Sindh:

* **Sindh (Main Overview):** Covers ancient Indus Valley civilization history (Mohenjo-daro), Sufi heritage, handicrafts (Ajrak, Sindhi Cap), and diverse ecosystems[cite: 4].
* **Karachi:** Highlights the coastal commercial powerhouse, Mazar-e-Quaid, colonial architecture, and culinary hubs[cite: 5].
* **Hyderabad:** Focuses on the historic city of perfumes, famous glass bangle markets (Shahi Bazaar), and academic centers[cite: 3].
* **Sukkur:** Detailed coverage of upper Sindh heritage, iconic architectural landmarks, and regional history.

---

## 🛠️ Features & Technologies

* **HTML5 Semantic Structure:** Built using proper semantic elements such as `<article>`, `<section>`, `<h1>`-`<h2>`, navigation links, and aligned image elements[cite: 3, 4, 5].
* **Multi-Page Navigation:** Internal linking (`index.html`, `karachi.html`, `hyderabad.html`, `sukkhar.html`) for multi-page browsing[cite: 3, 4, 5].
* **CSS3 Styling:** Custom theme classing (`.karachi`, `.hyderabad`, `.sukkhar`) with distinct dark color schemes and Google Fonts (`Roboto`)[cite: 3, 4, 5, 6].
* **Visual Media Integration:** Embedded image assets corresponding to each city's landmarks and landscapes[cite: 3, 4, 5].
